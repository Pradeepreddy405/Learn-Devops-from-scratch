# Networking & System Design Glossary

| Term | Simple meaning |
|---|---|
| ACL | Rule set controlling which traffic or actions are allowed |
| ALB | AWS managed Layer 7 load balancer |
| Authoritative DNS | DNS server publishing records for a zone |
| Backend | Application/service that handles a request |
| Cache | Temporary reusable copy of data |
| CIDR | Notation describing an IP range |
| DNS | System that maps names to records |
| Forward proxy | Proxy acting on behalf of clients |
| Health check | Probe used to assess target availability |
| Load balancer | Distributes connections or requests across targets |
| Nginx | Web server and reverse-proxy software |
| Reverse proxy | Proxy acting on behalf of backend servers |
| RTO | Target time to restore a service after disruption |
| RPO | Maximum targeted data-loss window |
| TLS | Protocol securing data in transit |
| TTL | Time a cached DNS or application object may remain valid |
| Upstream | Backend server group used by a proxy |
